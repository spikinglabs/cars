# Languages on cars.allo.land

The site is in three languages, each page at the same path in every one:

| Language | Code | Pages under | `<html lang>` |
|---|---|---|---|
| English | `en` | `/` | `en` |
| German | `de` | `/de/` | `de` |
| Simplified Chinese | `zh` | `/zh/` | `zh-Hans` |

The list lives in `LANGS` in `site/chrome/apply.py`. `python3 site/chrome/apply.py --check` (run in CI)
fails when a page is missing in any language.

## What is shared and what is per language

- **Head, header and footer** come from `site/chrome/`: `head.html` is shared; `header.html` and
  `footer.html` are English, `header.<code>.html` and `footer.<code>.html` the others. `apply.py`
  writes them into every page and fills in the `hreflang` links, the language menu, the manifest
  link and the country list.
- **Page text** is in each page's own HTML (`site/public/<slug>/index.html`,
  `site/public/de/<slug>/index.html`, `site/public/zh/<slug>/index.html`).
- **Page scripts** (`site/public/<slug>/app.js`, `assets/home.js`, `assets/site.js`) are shared by
  all languages. They read the language from `<html lang>` and pick their words from a table:

  ```js
  const lang = (document.documentElement.lang || "en").slice(0, 2);
  const de = lang === "de", zh = lang === "zh";
  const T = zh ? { … } : de ? { … } : { … };
  ```

  Use `T.locale` (`en-GB`, `de-DE`, `zh-CN`) for numbers and dates.
- **Country names** for the footer picker are in `site/public/regions.json` (`name.en/de/zh`).
- **Web app manifests**: `/manifest.webmanifest`, `/de/manifest.webmanifest`, `/zh/manifest.webmanifest`.

## Adding a page

1. Write the English page at `site/public/<slug>/index.html` with the `<!-- chrome:… -->` markers.
2. Copy it to `de/<slug>/` and `zh/<slug>/`, set `<html lang="de">` / `<html lang="zh-Hans">`,
   translate the text, and point internal links at `/de/…` / `/zh/…`.
3. Add every word the script shows to its `T` table, in all three languages.
4. Add the page to the nav in `header*.html` / the More sheet in `footer*.html` (all languages).
5. Run `python3 site/chrome/apply.py`.

## Adding a language

Add a row to `LANGS` in `apply.py`, write `header.<code>.html` and `footer.<code>.html`, translate
every page under `/<code>/`, add a manifest, add `<code>` to `HOMES` in `assets/site.js`, the `T`
tables, the country names in `regions.json`, the offline fallback in `sw.js`, and the `url_<code>`
links in `tools.json`.

## Chinese style notes

Simplified Chinese, informal 你. Units stay as written in Europe (€, kWh, km, L/100 km). Keep
German official names where people will meet them (KBA, TÜV, Bundesnetzagentur) and explain them
once. Glossary used so far: ad-hoc charging 即充即付, charger map 充电桩地图, charging cost
充电成本, price archive 价格档案, best time to charge 最佳充电时段, recalls 召回, new
registrations 新车登记, break-even 持平点 / 持平电价, dynamic tariff 动态电价, fuel car 燃油车.
